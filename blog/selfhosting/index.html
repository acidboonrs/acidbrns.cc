Selfhosting

Eigene Infrastruktur, eigene Kontrolle. Dienste selbst hosten statt auf fremde Cloud-Anbieter angewiesen zu sein.

Die Philosophie dahinter

Selfhosting bedeutet nicht zwangsläufig einen 24/7-Server im Keller. Es geht darum, die Kontrolle über die eigenen Daten zurückzugewinnen – ob auf einem Raspberry Pi, einem Rootserver oder einem alten Laptop.

Dieser Stack hier läuft auf einem Intel Xeon Gold 6454S: XMPP via Prosody, Git via Gitea, Monitoring, Blog und mehr. Alle Dienste sind öffentlich erreichbar, alle Daten bleiben lokal.
