URL Encoder / Decoder

URLs und Query-Parameter sicher kodieren und dekodieren. Unterstützt encodeURIComponent und vollständige URL-Kodierung.

Eingabe
Ausgabe
encodeURIComponent kodiert alle Sonderzeichen außer A-Z a-z 0-9 - _ . ! ~ * ' ( )
Vollständige URL kodiert alles außer Zeichen, die in URLs eine Bedeutung haben (: / ? # [ ] @ ! $ & ' ( ) * + , ; =)
