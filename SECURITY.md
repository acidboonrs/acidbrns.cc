# Security Policy

## Reporting a vulnerability

If you find a security issue, please report it **privately** — do not open a
public issue.

- **XMPP (preferred, OMEMO-encrypted):** `admin@acidbrns.cc`
- **Email:** `admin@acidbrns.cc`

Please include enough detail to reproduce (affected endpoint, steps, impact).
I aim to acknowledge reports within a few days and will keep you updated on the
fix. Responsible disclosure is appreciated — thank you.

## Scope

In scope: the registration/account web app, its API endpoints, and the
deployment configuration in this repository.

Out of scope: volumetric DoS, social engineering, and issues that require
physical or already-privileged access to the host.
