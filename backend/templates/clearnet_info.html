IP-Adresse

Bei VPN oder Tor weicht diese von deiner echten IP ab.

HTTP-Header

{% if headers %}
{% for key, value in headers.items() %} {{ key }} {{ value }} {% endfor %}
{% else %} Keine zusätzlichen Header. {% endif %}

Was bedeutet das?

  • IP-Adresse — Grobe Geolokation und ISP-Identifikation möglich. Mit Tor oder VPN versteckt.
  • User-Agent — Browser, OS und Version. Teil des Browser-Fingerprints.
  • Accept-Language — Spracheinstellung des Browsers. Kann zur Identifikation beitragen.
  • DNT / Sec-GPC — "Do Not Track" / "Global Privacy Control" — wird von den meisten Seiten ignoriert.
  • Accept-Encoding — Unterstützte Kompressionsverfahren (gzip, br, …).
