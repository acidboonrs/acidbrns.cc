🧅 Empfohlen: Nur über Tor nutzen

Wir empfehlen ausdrücklich, diesen XMPP-Server ausschließlich über Tor zu nutzen. So bleiben keine Verbindungs-Metadaten (deine IP, Standort, ISP) auf unserem Server zurück — selbst wir können nicht sehen, wer sich verbindet.

Android-Schnellstart mit Orbot:

  1. Orbot installieren (Tor-Proxy für Android)
  2. Orbot öffnen → VPN-Modus aktivieren
  3. Unter App-Auswahl deinen XMPP-Client (z.B. Conversations) hinzufügen
  4. Start drücken — Verbindung läuft jetzt über Tor
  5. In Conversations als Server acidbrns.cc eintragen, fertig

F-Droid (empfohlen) Google Play orbot.app

🔐 Komplett JavaScript-frei & datenschutz-fokussiert

Diese Seite läuft vollständig ohne JavaScript — kein Tracking, keine Analytics, kein Fingerprinting. Auch das Registrierungs-Formular funktioniert mit einem reinen Text-Browser (Lynx, w3m, Tor Browser im Safest-Modus).

  • Keine Third-Party-Skripte, kein CDN-Fetch, keine Cookies
  • Bot-Schutz ohne Cloudflare/Google — nur Honeypot + Mathe-Frage
  • Keine Telemetrie, kein Logging über das nginx-Standardmaß hinaus
  • Source ist offen — siehe GitHub

☕ Projekt unterstützen

Die Infrastruktur läuft auf Dedicated Hardware — 2× Intel Xeon Gold 6154, 256 GB ECC RAM, NVMe-RAID — vollständig selbst betrieben und finanziert. Der Traffic wird über einen Bulletproof-Server in einem datenschutzrechtlich sicheren Land reverse proxied, sodass die Ursprungs-IP zu keinem Zeitpunkt exponiert wird. Kein Managed Hosting, keine Datenweitergabe, keine Werbung. Die laufenden Kosten umfassen Strom, Colocation, Servermiete, Domains, SSL und Wartung. Wer den Betrieb unterstützen möchte — jede Spende hilft direkt. Danke.
